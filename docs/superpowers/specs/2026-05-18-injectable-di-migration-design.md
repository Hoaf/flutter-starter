# Injectable DI Migration Design

## Goal

Migrate dependency injection from manual registration in `service_locator.dart` to code-generation using the `@injectable` package, reducing boilerplate and making future class additions annotation-only.

## Context

- `injectable: ^2.5.0` and `injectable_generator` already present in `pubspec.yaml`
- `build_runner: ^2.4.15` already present
- Current `service_locator.dart` manually registers ~25 classes
- `injector.dart` exists but is entirely commented-out legacy code — to be deleted

## Approach

Keep `service_locator.dart` as the DI entry point (renamed internals only). Replace its body with `@InjectableInit()`. Add `injection_module.dart` for third-party class (`FlutterSecureStorage`) that cannot be annotated directly. Annotate all 23 project classes. Run `build_runner` to generate `service_locator.config.dart`.

`main.dart` and all `getIt<X>()` call sites remain unchanged.

## File Changes

| Action | File |
|---|---|
| Rewrite | `lib/di/service_locator.dart` |
| Create | `lib/di/injection_module.dart` |
| Auto-generated (do not edit) | `lib/di/service_locator.config.dart` |
| Delete | `lib/di/injector.dart` |
| Annotate | 23 source files (listed below) |

## New / Rewritten Files

### `lib/di/service_locator.dart`
```dart
import 'package:get_it/get_it.dart';
import 'package:injectable/injectable.dart';
import 'service_locator.config.dart';

final getIt = GetIt.instance;

@InjectableInit()
Future<void> setupLocator() async => getIt.init();
```

### `lib/di/injection_module.dart`
```dart
import 'package:flutter_secure_storage/flutter_secure_storage.dart';
import 'package:injectable/injectable.dart';

@module
abstract class InjectionModule {
  @lazySingleton
  FlutterSecureStorage get secureStorage => const FlutterSecureStorage();
}
```

## Build Step

After all annotations are added:
```bash
cd C:/project/nt-flutter-starter/flutter
flutter pub run build_runner build --delete-conflicting-outputs
```

This generates `lib/di/service_locator.config.dart`. Do not edit this file manually.

## Verification

```bash
flutter analyze
flutter test
```

All existing tests must pass — unit tests do not use `get_it` and are unaffected by this change.

## What Does NOT Change

- `main.dart` — `setupLocator()` call unchanged
- All `getIt<X>()` call sites in presentation layer
- Unit tests
- `pubspec.yaml` — packages already present
